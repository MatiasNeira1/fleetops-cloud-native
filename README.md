# FleetOps

FleetOps es una plataforma Cloud Native para la gestión logística
y de flotas de vehículos.

El proyecto está diseñado para demostrar arquitectura distribuida,
microservicios, procesamiento de telemetría, DevSecOps,
Infrastructure as Code, observabilidad y Microsoft Azure.

## Stack

### Frontend
- React
- TypeScript

### Backend
- Java
- Spring Boot

### Datos
- PostgreSQL

### Azure
- Azure Container Apps
- Azure Container Registry
- Azure Event Hubs
- Azure Service Bus
- Azure Web PubSub
- Azure Key Vault
- Azure Monitor
- Application Insights
- Log Analytics

### DevOps
- Docker
- Terraform
- GitHub Actions
- Grafana k6

### DevSecOps
- CodeQL
- Trivy
- Gitleaks
- OWASP ZAP

## Arquitectura

La plataforma utiliza una arquitectura distribuida,
orientada a eventos y basada en microservicios.
